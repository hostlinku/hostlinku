# Hostlinku

Hostlinku is an AI model gateway for applications and coding tools. Use a Hostlinku API key with the OpenAI or Anthropic SDK.

[Documentation](https://docs.hostlinku.com/) · [Models and pricing](https://hostlinku.com/models) · [Console](https://console.hostlinku.com/)

## Start here

- [Python quickstart](https://github.com/hostlinku/hostlinku-python-quickstart): List the models available to your key and send your first request.
- [OpenCode starter](https://github.com/hostlinku/hostlinku-opencode-starter): Generate a custom provider configuration from the models available to your key.
